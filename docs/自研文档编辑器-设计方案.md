# 自研富文本文档编辑器（编码实现版）
## 一、文档说明
### 1.1 文档目的
本文档明确自研Web端富文本文档编辑器的完整产品功能、交互逻辑、数据规范与技术实现要求，为大模型编码落地提供精准可执行的需求依据，最终实现类语雀体验的结构化在线文档编辑能力。

### 1.2 适用范围
覆盖编辑器前端核心模块的全部需求，包含顶部工具栏、正文编辑内核、右侧大纲面板三大核心模块，以及基础富文本排版、结构化内容渲染能力；不含后端存储、多人实时协同、权限管理等服务端能力。

### 1.3 目标读者
大模型编码实现人员、前端开发人员。

## 二、产品定位与核心目标
### 2.1 产品定位
轻量级结构化Web富文本编辑器，对标语雀文档的基础编辑体验，支持标准语义的富文本排版、标题层级大纲导航、常用格式化操作，满足技术方案、需求文档等专业文档的撰写与阅读场景。

### 2.2 核心目标
1. 实现完整的富文本编辑内核，覆盖标题、正文、列表、格式修饰等全量基础排版能力
2. 实现右侧实时大纲面板，支持标题层级折叠展开、点击跳转、滚动高亮联动
3. 顶部工具栏提供可视化格式操作入口，与编辑区状态双向联动
4. 输出标准化的结构化文档数据模型，支持序列化存储与回显
5. 交互与视觉对齐主流在线文档使用习惯，操作低学习成本

## 三、整体模块架构
编辑器采用模块化拆分设计，便于编码分模块实现，模块间通过统一事件与数据联动：

| 模块名称 | 职责说明 | 联动关系 |
|----------|----------|----------|
| 工具栏模块（Toolbar） | 顶部操作栏，提供所有格式操作的可视化入口 | 操作指令下发到编辑内核；同步编辑区的格式状态 |
| 编辑内核模块（Editor） | 正文编辑核心，负责内容输入、格式渲染、选区操作、数据维护 | 内容变更时通知大纲模块更新；接收工具栏的格式指令 |
| 大纲面板模块（Outline） | 右侧导航栏，解析标题层级、提供导航能力 | 监听编辑区标题变更实时更新；点击条目触发编辑区滚动 |

## 四、核心功能需求
### 4.1 顶部工具栏
#### 4.1.1 布局规范
工具栏固定在页面顶部，高度48px，背景为纯白色，底部1px浅灰色边框，不随页面滚动消失。
工具栏横向分为7个操作组，组间用细分割线区隔，从左到右依次为：
1. 基础操作组：新建、撤销、重做
2. 段落样式组：段落样式下拉选择、字号选择
3. 行内格式组：加粗、斜体、下划线、删除线
4. 颜色设置组：文字颜色、文字背景色
5. 段落排版组：左对齐、居中对齐、右对齐、有序列表、无序列表、任务列表
6. 插入内容组：插入链接、插入图片、插入引用、插入代码块、插入分割线
7. 视图控制组：大纲显示/隐藏、全屏编辑

#### 4.1.2 功能明细
| 功能项 | 功能描述 | 交互与快捷键规则 |
|--------|----------|------------------|
| 撤销 | 回退上一步编辑操作 | 点击触发，快捷键 `Ctrl+Z` 同步生效；无可撤销操作时按钮置灰不可点击 |
| 重做 | 恢复已撤销的编辑操作 | 点击触发，快捷键 `Ctrl+Y` 同步生效；无可重做操作时按钮置灰不可点击 |
| 段落样式下拉 | 切换当前段落的标题/正文样式 | 下拉选项包含：正文、标题1、标题2、标题3、标题4；选中后光标所在段落立即应用对应样式 |
| 字号选择 | 设置文本字号 | 默认15px，支持12/14/15/16/18/20/24px可选；选中选区时修改选中文本字号，无选区时修改后续输入的默认字号 |
| 加粗 | 切换文本加粗状态 | 选中文本后点击切换，快捷键 `Ctrl+B`；无选区时切换后续输入的加粗状态 |
| 斜体 | 切换文本斜体状态 | 选中文本后点击切换，快捷键 `Ctrl+I`；无选区时切换后续输入的斜体状态 |
| 下划线 | 切换文本下划线状态 | 选中文本后点击切换，快捷键 `Ctrl+U`；无选区时切换后续输入的下划线状态 |
| 删除线 | 切换文本删除线状态 | 选中文本后点击切换；无选区时切换后续输入的删除线状态 |
| 文字颜色 | 设置文本字体颜色 | 点击弹出颜色选择面板，支持基础色板与自定义取色；选中文本修改选区内颜色，无选区修改后续输入颜色 |
| 背景色 | 设置文本高亮背景色 | 点击弹出颜色选择面板，提供常用高亮色系；选中文本修改选区内背景色，无选区修改后续输入背景色 |
| 左/居中/右对齐 | 设置段落对齐方式 | 点击后光标所在段落切换对应对齐方式，默认左对齐 |
| 有序列表 | 切换有序列表格式 | 光标所在段落转为数字序号列表，再次点击取消；支持 `Tab` 升级层级、`Shift+Tab` 降级层级 |
| 无序列表 | 切换无序列表格式 | 光标所在段落转为圆点列表，再次点击取消；支持 `Tab` 升级层级、`Shift+Tab` 降级层级 |
| 任务列表 | 切换待办任务列表 | 光标所在段落转为带复选框的任务项，再次点击取消；复选框可点击勾选，勾选后文本自动添加删除线 |
| 插入链接 | 为选中文本添加超链接 | 选中文本后点击，弹出弹窗输入链接地址与显示文本，确认后生成可点击超链接，新标签页打开 |
| 插入图片 | 在光标位置插入图片 | 支持本地上传、输入在线图片URL两种方式；图片最大宽度不超过编辑区宽度，按比例自适应 |
| 插入引用 | 段落转为引用块样式 | 光标所在段落转为引用格式，左侧带蓝色竖线标识，文字灰度降低；再次点击取消 |
| 插入代码块 | 插入多行代码容器 | 在光标位置插入代码块，等宽字体渲染，浅灰背景，支持多行代码输入 |
| 插入分割线 | 插入水平分隔线 | 在光标位置下方插入一条浅灰色水平分割线 |
| 大纲开关 | 切换右侧大纲面板显隐 | 点击切换显示/隐藏，默认显示大纲面板 |
| 全屏切换 | 切换全屏编辑模式 | 点击后编辑器占满浏览器视口，隐藏页面其他元素；再次点击退出全屏 |

#### 4.1.3 状态联动规则
- 光标移动到不同段落时，工具栏同步高亮当前段落对应的格式状态（如光标在标题2段落，段落样式下拉自动显示“标题2”）
- 选中文本包含对应格式时，工具栏对应按钮呈现激活高亮状态

### 4.2 编辑内核模块
#### 4.2.1 内容层级与样式规范
严格对齐语雀视觉规范，各级内容默认样式如下：

| 样式类型 | 字号 | 字重 | 行高 | 上下外边距 | 说明 |
|----------|------|------|------|------------|------|
| 标题1（H1） | 28px | 700 | 1.5 | 24px | 文档一级大标题 |
| 标题2（H2） | 22px | 700 | 1.5 | 上20px、下12px | 章节二级标题 |
| 标题3（H3） | 18px | 600 | 1.5 | 上16px、下8px | 小节三级标题 |
| 标题4（H4） | 16px | 600 | 1.5 | 上12px、下8px | 四级子标题 |
| 正文 | 15px | 400 | 1.7 | 8px | 普通正文段落 |

#### 4.2.2 基础编辑能力
1. **输入与光标控制**
   - 支持普通文本输入，`Enter` 新建段落，`Shift+Enter` 软换行
   - 支持光标方向键移动、鼠标拖拽选区、`Ctrl+A` 全选
   - 支持复制、剪切、粘贴；默认粘贴保留基础格式，`Ctrl+Shift+V` 纯文本粘贴
   - 空段落显示灰色占位提示“请输入正文”，输入内容后自动消失

2. **列表能力**
   - 有序列表：自动按数字序号递增，支持多级缩进，二级列表自动切换为小写字母序号
   - 无序列表：一级为实心圆点，二级为空心圆点，三级为实心方块
   - 任务列表：复选框可独立点击，勾选后对应文本自动添加中划线并降低灰度

3. **特殊内容块**
   - 引用块：左侧2px蓝色竖线，左内边距12px，文字颜色为浅灰色
   - 代码块：浅灰色背景，等宽字体（Consolas/Monaco/系统等宽字体），内边距12px，支持换行与缩进
   - 分割线：1px浅灰色实线，上下外边距16px
   - 超链接：主色调蓝色文字，鼠标悬浮显示下划线，点击新标签页打开地址

#### 4.2.3 数据模型规范
编辑器内容必须支持序列化为结构化JSON，用于存储、回显与数据传输，核心结构如下：
```json
{
  "documentId": "string",
  "title": "文档主标题",
  "content": [
    {
      "type": "heading",
      "level": 1,
      "text": "概要设计",
      "marks": []
    },
    {
      "type": "paragraph",
      "text": "当前产品研发和客户交付链路中缺少统一的业务对象链路",
      "marks": [
        { "type": "bold", "start": 2, "end": 6 }
      ]
    },
    {
      "type": "list",
      "listType": "bullet",
      "items": [
        {
          "text": "产品主数据缺少统一维护入口",
          "checked": false,
          "level": 1
        }
      ]
    }
  ]
}
```
- 内容以块（Block）为最小单位，每个块包含类型、内容、格式标记
- 行内格式（加粗、斜体、颜色、链接）通过 `marks` 数组标记，通过起止位置定位生效范围

### 4.3 大纲面板模块
#### 4.3.1 布局规范
- 固定在编辑器右侧，默认宽度240px，高度与编辑区可视区域一致，内容超出时纵向滚动
- 面板顶部显示“大纲”标题，支持宽度拖拽调整，最小宽度180px，最大宽度360px

#### 4.3.2 核心功能
1. **实时生成与更新**
   - 编辑区内容变更时，实时解析所有H1-H4标题，自动生成层级化大纲树
   - 标题按层级缩进展示：H1无缩进，H2缩进16px，H3缩进32px，H4缩进48px

2. **折叠与展开**
   - 包含子级标题的父级标题前显示折叠/展开箭头图标
   - 点击箭头可折叠/展开该标题下的所有子级标题，文档默认全部展开
   - 折叠状态仅在当前页面临时生效，刷新后恢复全部展开

3. **导航与联动**
   - 点击任意大纲条目，编辑区平滑滚动到对应标题位置
   - 编辑区滚动时，当前可视区域最顶部的标题在大纲中高亮标记
   - 文档无任何标题时，面板显示“暂无标题，添加标题后自动生成大纲”空状态提示

## 五、视觉与交互规范
### 5.1 整体页面布局
- 页面采用三栏结构：页面背景、中间编辑区、右侧大纲面板
- 编辑区内容最大宽度800px，水平居中，左右两侧自适应留白
- 页面背景色为浅灰色，编辑区背景为纯白色

### 5.2 视觉色板
| 用途 | 色值 |
|------|------|
| 主色调（激活、链接、高亮） | #165DFF |
| 正文文字 | #1F2329 |
| 次要文字（占位、提示） | #86909C |
| 边框、分割线 | #E5E6EB |
| 页面背景 | #F7F8FA |
| 编辑区背景 | #FFFFFF |

### 5.3 通用交互规则
- 所有可点击元素鼠标悬浮时，指针切换为手型
- 按钮、弹窗统一采用4px圆角
- 滚动、切换类操作添加平滑过渡动画，时长150ms

## 六、非功能需求
1. **性能**：1000行文档内输入无卡顿，输入延迟≤100ms；大纲更新延迟≤200ms；页面首屏加载≤1.5s
2. **兼容性**：支持Chrome、Edge、Firefox最新两个大版本，支持Safari 14+；适配1366*768及以上分辨率
3. **可扩展性**：工具栏、编辑内核支持插件化扩展，新增功能无需重构核心架构；数据模型支持扩展新的内容块类型

## 七、编码实现要求
### 7.1 技术栈参考
- 前端框架：React 18+ 或 Vue 3+
- 编辑内核：基于 `contenteditable` 原生封装，或基于 ProseMirror/TipTap 二次开发
- 样式方案：CSS Modules 或 Tailwind CSS
- 构建工具：Vite

### 7.2 代码结构要求
- 按模块拆分目录：`components/Toolbar`、`components/Editor`、`components/Outline`
- 核心编辑逻辑与UI组件分离，格式操作、数据序列化封装为独立工具函数
- 提供统一的事件回调：内容变更 `onChange`、标题变更 `onHeadingChange`
- 关键函数添加注释，明确入参、出参与功能说明

### 7.3 交付要求
1. 可独立运行的前端项目，执行启动命令后可直接体验完整编辑能力
2. 提供文档内容导入/导出方法，支持上述JSON格式的读写
3. 包含README文档，说明项目启动方式、API用法与扩展规则
